# Decoding Customer Value

## Project Overview
This project analyzes customer purchasing behavior to identify high-value customer segments and generate actionable business insights. Using Python, SQL, and Power BI, the data was cleaned, segmented, and visualized to support customer retention and marketing strategies.

## Objectives
- Clean and preprocess customer transaction data.
- Perform customer segmentation.
- Analyze customer value and purchasing patterns.
- Build an interactive Power BI dashboard.
- Recommend data-driven business strategies.

## Tools & Technologies
- Python (Pandas)
- SQL
- Power BI
- Microsoft Excel

- customer_value_analysis.ipynb
- cleaned_dataset_for_sql.csv
- Customer Value Dashboard.pbix
- Executive Summary.docx

## Key Insights
- Identified high-value customer segments.
- Analyzed spending, purchase frequency, and retention.
- Created an interactive Power BI dashboard.
- Provided recommendations to improve customer engagement and business growth.
